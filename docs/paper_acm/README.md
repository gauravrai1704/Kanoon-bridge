# Full paper (ACM acmart, sigconf)

`kanoon_bridge_acm.tex` + `references.bib` + `figures/`. Overleaf has acmart built in: upload this
folder (or the zip) and compile with pdfLaTeX. For submission switch to
`\documentclass[sigconf,review,anonymous]{acmart}` and fill the conference macros.

Checked: the body compiles with no errors and no overfull lines (tested under a stand-in class;
acmart itself is standard on Overleaf). Open items are marked with red \todo{}: E20 (LLM run),
affiliation, repository URL, annotation results, a systematic E19/E2 error analysis, and
bibliography entries marked TODO in references.bib.
